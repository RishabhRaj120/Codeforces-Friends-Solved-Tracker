# Privacy Policy

Codeforces Friend Solved Tracker does not collect, store, or transmit any personal data.

- No tracking or analytics of any kind.
- No external backend or server.
- API credentials entered by the user are stored locally in Chrome's storage API and never leave the browser.
- The extension only reads Codeforces pages and API responses required to display the friend count widget.

This extension is a client-side browser tool. All data stays on your device.
